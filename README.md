# SORT/CODE LAB · C 排序算法交互实验室

一个纯前端、零依赖的 C 排序算法逐步可视化页面：每一帧都对应真实 C 代码中的一行、一次比较或一次移动，适合边看代码边理解算法是如何运转的。

## 启动

```powershell
cd c-sort-lab
node server.js
```

打开：<http://127.0.0.1:4180/>

也可以直接双击 `index.html`；通过 `server.js` 打开可以保证剪贴板、字体和脚本行为一致。

## 现在包含什么

| # | 算法 | 教学重点 |
|---|------|----------|
| 01 | 冒泡排序 | 相邻逆序对、提前终止、每轮最大值归位 |
| 02 | 选择排序 | 无序区最小值、交换次数、稳定性代价 |
| 03 | 插入排序 | 已排序前缀、key 暂存、元素后移 |
| 04 | 希尔排序 | 增量 gap、分组插入、复杂度直觉 |
| 05 | 归并排序 | 递归拆分、左右队首、辅助数组 tmp、写回 |
| 06 | 快速排序 | Lomuto 分区、基准归位、递归区间 |
| 07 | 堆排序 | 完全二叉树数组表示、下沉、建堆、取堆顶 |

每个算法都提供：

- 可执行的逐步轨迹（初始 → 比较 → 移动/交换 → 写回 → 完成）。
- 右侧真实 C 代码，当前执行行自动高亮；点击代码行可跳到该行第一次执行。
- 当前操作的文字解释与「为什么」说明。
- 变量观察卡：`i`、`j`、`key`、`gap`、`pivot`、`largest`、`lo/hi` 等。
- 比较、写入、交换计数，以及算法稳定性和额外空间说明。
- 堆排序额外显示二叉树视图；归并排序额外显示 `tmp` 辅助数组。
- 每次单步都有实时合成的音效反馈；比较音高随元素值变化，交换/写入是低频脉冲，完成时播放收束和弦。
- C 代码面板使用无连字字体，`>=`、`<=`、`!=` 都按 ASCII 字符原样显示，避免编程字体把 `>=` 连成 `≥`。

## 操作

- 点击左侧算法切换实现。
- 拖动时间轴或点「上一步 / 下一步」逐帧执行。
- 「自动播放」可调速；`Space` 播放/暂停。
- 输入 3–18 个 1–99 的整数，支持重复值；「应用」重新生成轨迹。
- 窄屏下元素超过 12 个时，柱顶数值会隔位标注，当前比较/指针项始终保留标注，避免标签互相覆盖。
- 预设：随机、近乎有序、逆序、少量重复。
- 顶栏音效按钮或 `M` 切换声音；首次点击播放/单步后启用 Web Audio，静音偏好保存在本机。
- `←` / `→` 单步，`R` 复位，`N` 新数据，`M` 音效，`G` 打开学习指南，`1–7` 切换算法，`Esc` 关闭面板。
- 页面底部还提供当前算法的三个记忆点和三个读代码提醒。

## 手机端

- 手机宽度下切换为单列布局；窗口 ≤ 560px 时顶栏固定在顶部，音效和学习指南随时可点。
- 算法索引改为紧凑双列，仅保留算法名；复杂度与稳定性在选中后的标题区显示。
- 数组输入框使用 16px 字号，避免 iOS Safari 聚焦时自动放大；下方会显示当前轨迹的完整数值 chips，避免长数组被单行输入框截断。
- 学习指南在手机上铺满窗口，内容区独立滚动，底部「开始实验」按钮始终可见。
- 代码区保持横向独立滚动；页面本身不会出现横向溢出。

## 文件结构

```text
c-sort-lab/
├─ index.html       页面结构
├─ favicon.svg      站点图标（现代浏览器）
├─ favicon.ico      站点图标（兼容回退）

│  └─ style.css     深色实验室视觉、响应式布局
├─ js/
│  ├─ algorithms.js 七个算法的轨迹生成器、C 代码与教学文案
```

没有构建步骤，没有 CDN，没有外部 3D/图表库。算法轨迹在浏览器内存中生成，数据不会离开本机。

## 阅读方式建议

1. 先选「冒泡排序」，不停点「下一步」，观察橙色比较与红色移动的区别。
2. 再切到「归并排序」，看 `tmp` 辅助数组如何合并，以及写回原数组的时刻。
3. 最后看「快速排序」和「堆排序」：前者关注 pivot 一次归位，后者关注树上的父子索引关系。
4. 输入同一组数据，对比不同算法的比较次数、写入次数和排序过程。
